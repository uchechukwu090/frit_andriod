# FRIT — Privacy Policy

Last updated: October 2026.

## 1. Data we process
- **Screen text and installed-app list**: sent to our server to operate the agent
  loop (open apps, tap, verify). Screen images are processed for UI analysis only.
- **Contacts**: names you ask us to call/message are resolved on-device; numbers
  are used only to place that call/message.
- **Microphone/audio**: voice commands are transcribed (server or on-device);
  call conversations are transcribed to complete the requested task.
- **Account data**: your user ID, tier, usage counters, wallet ledger, payment
  references. No card numbers are ever collected (payments are bank/crypto transfer).
- **Diagnostics**: crash logs, error messages (no secrets).

## 2. What we never do
- Never sell personal data. Never use screen content for advertising.
- Transaction PINs are typed straight into app fields and never stored server-side.

## 3. Sharing
- AI providers (text/audio/image/video generation) receive task content under
  their policies. Free-tier routes may retain prompts for abuse monitoring.
- Public blockchain explorers receive transaction IDs you submit for verification.
- HuggingFace serves the optional on-device model download.

## 4. Retention & deletion
- Agent sessions and screen data: 90 days. Ledger and billing records: 5 years
  (financial record-keeping). Message in-app feedback with "DELETE MY DATA" plus
  your user ID and we erase everything erasable within 14 days.

## 5. Security
TLS in transit, tokens on device only, admin actions on a separate secret,
hash-chained money ledger. No system is perfect — report holes via feedback.
